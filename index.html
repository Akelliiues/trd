ติดตั้ง TradingTools บนอุปกรณ์ของคุณ

✨ ติดตั้งเป็นแอปพลิเคชัน Standalone ทันที
เปิดใช้งานแบบเต็มจอ ไม่มีแถบ URL ประสิทธิภาพสูงเหมือน Native App
📌 คำแนะนำการติดตั้งตามประเภทอุปกรณ์:
🍎 สำหรับ iPad / iPhone (Safari)
  1. เปิดเว็บไซต์นี้ด้วยเบราว์เซอร์ Safari
  2. แตะที่ปุ่มแชร์ Share (แถบด้านล่างหรือด้านบน)
  3. เลื่อนลงมาแล้วเลือก "เพิ่มไปยังหน้าจอโฮม" (Add to Home Screen)
  4. กด "เพิ่ม" (Add) มุมขวาบน จะได้ไอคอนแอปบนหน้าจอ ใช้งานแบบเต็มจอ 100%
🤖 สำหรับ แท็บเล็ต / มือถือ Android (Chrome)
  1. เปิดเว็บไซต์นี้ด้วย Google Chrome
  2. แตะปุ่มเมนู จุดสามจุด (⋮) มุมขวาบน
  3. เลือก "ติดตั้งแอป" (Install App) หรือ "เพิ่มลงในหน้าจอหลัก"
  4. ยืนยันการติดตั้ง แอปจะถูกติดตั้งใน Drawer และหน้าจอหลัก
💻 สำหรับ Windows PC / Mac (Chrome / Edge)
  1. สังเกตไอคอน ติดตั้ง บนแถบที่อยู่ URL (Address bar)
  2. หรือกดปุ่มเมนู (⋮) แล้วเลือก "ติดตั้ง TradingTools..." (Install TradingTools)
  3. สามารถเปิดใช้งานเป็นหน้าต่างอิสระ ปักหมุดบน Taskbar ได้ทันที
